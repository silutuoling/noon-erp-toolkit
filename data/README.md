# data/ 数据说明

四个文件，全部由工具站真源代码生成，不是手抄。

| 文件 | 内容 |
|---|---|
| `markets.json` | 三站元信息：VAT 税率、币种、最低佣金、月度/长期/不可售仓储费、退货管理费、各张费率表的生效日 |
| `referral-fees.json` | 70 个类目的佣金费率阶梯，AE / SA / EG 三站独立（同类目不同站点费率不同，例如香水 AE 14% / SA 15% / EG 11.5%） |
| `fbn-outbound.json` | FBN 出库费，按尺寸档 × 重量档 × 售价档（AE/SA 分 ASP≤25 与 >25 两档） |
| `hs-rules.json` | 沙特 / 阿联酋 / 埃及的 HS 位数结构规则、每段含义、97 章章节表 |
| `duty-defaults.json` | 三站进口关税 / VAT / 进口服务费的默认值与官方查询入口（含国别前置要求） |
| `title-rules.json` | 16 个促销/绝对化词、14 项标题检查规则与评分口径 |
| `banned-words.json` | 4 组共 61 个风险表述（绝对化 / 医疗功效 / 仿冒 / 疑似品牌） |

对应的在线版见根目录 README 的模块对照表。

## 每个文件都带 `_meta`

```json
{
  "_meta": {
    "source_file": "web/src/pages/toolkit/rates.ts",
    "official_source": { "ae": "...", "sa": "...", "eg": "..." },
    "fetched_at": "2026-10-22",
    "online_tool": "https://noonmate.com/tool/commission",
    "disclaimer": "..."
  }
}
```

- `fetched_at` 是官方数据的抓取日期，**不是**文件生成日期
- 改数据时，如果官方有新值，应该新增并更新生效日，而不是直接覆盖旧值 ——
  否则历史账单没法复核

## 四条必须知道的口径

**1. 分站点独立。** AE / SA / EG 是三个独立合同，同类目费率不同。任何「统一费率」的写法都是错的。

**2. 费率是边际阶梯，不是整单单价。** 见根 README 的珠宝算例。

**3. 费率不含 VAT。** 官方原文 "All fees are exclusive of VAT"，VAT 要单独叠加。

**4. 每条都带生效日。** 官方一年调几次，做历史对账时要按生效日取当时的费率。

## 单位

- 金额一律是**站点本币**（AED / SAR / EGP），不是人民币、不是美元
- 费率单位是**百分数**（`27` 表示 27%，不是 0.27）
- 重量单位是 **kg**，尺寸单位是 **cm**
- 仓储费单位是 **每立方英尺**

## 不在这四个文件里的东西

- **汇率**：每天变，静态快照会误导，不提供
- **品牌专属费率**：官方放在单独 Excel 例外表，未收录
- **FBP（自发货）费率**：与 FBN 是两套表，未收录
- **商品 → HS 编码映射**：不做归类，只校验结构
